## 解决什么问题

写公文最花时间的不是内容，是格式。一键生成空白模板，跳过所有行距字号调整。

生成符合《党政机关公文格式》的空白 Word 模板，页边距、行距、字体一次到位

## 这是什么

这是一个 **AI Skill** 包——把一套特定的工作方法封装成可复用的指令集，
让 AI 智能体（WorkBuddy / Claude Code / Codex 等）装上之后，就能按这套方法干活，
而不是每次从头解释一遍要求。

`SKILL.md` 是核心文件，包含完整的操作流程、避坑规则和验证方式。

## 安装

把整个目录放进你的 skills 目录：

```bash
# WorkBuddy / Claude Code
cp -r gongwen-blank-template ~/.workbuddy/skills/

# 或项目级
cp -r gongwen-blank-template .workbuddy/skills/
```

装好后让 AI 读取 `gongwen-blank-template/SKILL.md` 即可生效。
